# miniPBX

Мини-АТС на Asterisk для слабого VPS (работает на машине с ~550 МБ RAM).
Один SIP-телефон + транк провайдера + веб-админка. Установка в одну команду.

## Быстрый старт (чистый Ubuntu 22/24/26, ~2 минуты)

```bash
git clone https://github.com/mkspoi/miniPBX.git
cd miniPBX
sudo bash install.sh
```

Скрипт сам: поставит пакеты, сконфигурирует Asterisk, админку и nginx,
откроет порты в ufw, выпустит HTTPS-сертификат (если укажете домен) и
**сгенерирует пароли** (админки и SIP), которые напечатает в конце.

Без вопросов, одним вызовом:

```bash
sudo PBX_DOMAIN=pbx.example.com bash install.sh
```

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `PBX_DOMAIN` | домен админки (переходим на HTTPS) | пусто = HTTP-only |
| `PBX_SIP_PORT` | SIP-порт (нестандартный — от сканеров) | 21967 |
| `PBX_RTP_START/END` | диапазон RTP | 10000–10050 |
| `PBX_EXT` | имя внутреннего номера | phone1 |
| `PBX_EXT_PWD` | пароль SIP-аккаунта | сгенерировать |
| `PBX_ADMIN_PWD` | пароль админки | сгенерировать |

## Дальше (2 минуты в браузере)

1. Открыть `https://<домен>/root/` — админка живёт на скрытом пути, корень сайта отдаёт 404
2. Ввести логин/пароль SIP-провайдера и нажать «Сохранить и применить» — транк сконфигурируется и зарегистрируется сам
3. В софтфоне указать: сервер `<домен>`, порт из установки (UDP), логин/пароль SIP из распечатки; кодек — **ALAW**
4. Набирать можно в любом формате: `+7…`, `8…`, `00…`, `9…` — приведётся к `7XXXXXXXXXX`

## Что внутри

- **Веб-админка** — чистый Python 3 stdlib, без зависимостей: форма транка, вкл/выкл транка, настройки телефона, статус регистрации, прослушивание записей
- **Защита от подбора пароля**: 3 неверных ввода с одного IP → пауза 30 минут (429)
- **Запись разговоров**: встроена, по умолчанию выключена глобальным флагом `RECORD_ENABLED` в extensions.conf (включить: `YES` + `asterisk -rx "dialplan reload"`); записи в `/var/spool/asterisk/monitor`
- **Кодеки**: только ALAW на телефоне и на транке — без перекодировок и «роботизированного» звука

## Структура

```
install.sh                       установка «в одну команду»
asterisk/
  extensions.conf                диалплан (нормализация номера, запись-выключатель)
  pjsip.conf                     транспорт (нестандартный SIP-порт)
  rtp.conf                       диапазон портов RTP
  pjsip_phones.conf.example      шаблон внутреннего номера
  pjsip_trunk.conf.example      шаблон транка (генерируется админкой)
pbx-admin/
  app.py                         веб-админка (Python 3 stdlib only)
  config.json.example            пример конфига (создаётся install.sh)
  pbx-admin.service              systemd-юнит
nginx/
  pbx-nossl.conf                 vhost: /root/ → 127.0.0.1:8090, остальное 404
  pbx.conf                       тот же vhost после certbot (с TLS), для справки
```

## Провайдер

Шаблон транка содержит `identify` для Novofon/Zadarma (`37.139.38.0/24`).
Для другого оператора замените подсеть в шаблоне `trunk_conf` внутри `pbx-admin/app.py`
(или добавьте DNS-имя провайдера) — остальное универсально.
